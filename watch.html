🧠 CodeVoidOS

A modular, app-driven embedded operating system designed for the LILYGO T-Display-S3 ESP32-S3 with a built-in AMOLED display, physical buttons, and hardware expansion support.

📦 Hardware Overview

  • Base Board: LILYGO T-Display-S3 ESP32-S3
  • Screen: 1.91" AMOLED (RM67162)
  • Buttons:
    • Top right – Power
    • Middle right – Select
    • Bottom right – Rotary encoder with press
  • Strap: Leather cuff
  • Top Connector: Modular extension slot with VCC, GND, DATA+, DATA−

🧩 Slot System (C-Slot)

Each slot exposes the following pins:

  • VCC – Power
  • GND – Ground
  • DATA+ – Module → Watch
  • DATA− – Watch → Module

Modules announce themselves by pulling DATA+ high on boot. Watch responds by pulling DATA− high. Module then sends an identity packet.

📜 Example Module ID Packet

typedef struct {

🧠 Deva Modules (System-Wide Extensions)

Devas are special modules that provide global hardware capabilities accessible by all apps.

🔌 Defined Deva Modules

ModuleCapabilityFlag
SpeakerAudio output (buzzer or amp)DEV_CAP_AUDIO
Audio JackAnalog 3.5mm outputDEV_CAP_AUDIO
SD CardData storage via SPIDEV_CAP_STORAGE

✅ System Integration

  • Flags like DEV_CAP_AUDIO allow apps to detect and use features
  • The OS tracks Deva modules using a central deva_manager
  • Apps can call APIs like has_deva_capability() and play_beep()

🔧 App Registry

The OS supports both static and dynamic apps:

typedef struct {
  const char* app_id;
  const char* name;
  const uint8_t* icon;
  void (*entry_point)(SlotComm*);
  bool is_dynamic;
  bool is_deva_owned;
  uint8_t slot_id;
} AppEntry;

📲 Launcher + Home Screen

  • Dynamically generates grid of apps from registry
  • Home button returns here from any app
  • Top bar always shows time, battery, signal

🔄 App Communication

Apps can take full control of a module's communication lines after being launched.

💬 Vision

CodeVoidOS is a smart, modular wearable platform designed around real-time plug-in hardware modules. It combines:

  • Retro-tech styling
  • Dynamic software registry
  • System-wide services from Deva modules
  • Custom apps and a full runtime on the ESP32-S3

The final design merges physical hardware expandability with a flexible OS runtime to create a wearable device worthy of the Void.
